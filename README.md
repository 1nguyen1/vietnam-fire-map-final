# The Last Firebender — Vietnam Fire Calendar (NASA Space Apps 2026)

**Team 268LTK** · Challenge: *Harmonization of MODIS and VIIRS Hot Spots*
**Live app:** https://deployfindfire.vercel.app

One consistent fire-hotspot record for Vietnam from 2003 to today, on the VIIRS S-NPP 375 m scale, for 34 provinces:
1 km fire map, daily view, patrol-priority map, forest vs. cropland filter, and a compare tool (two provinces or two periods, CSV/PNG export).

## How the harmonization works
- MODIS (Aqua, 1 km) and VIIRS (S-NPP, 375 m) detect different fire sizes, so a naive splice shows a fake ~7× jump in 2012.
- Using the years both satellites flew together, a **Poisson generalized linear model** on a 0.25° × month grid converts MODIS counts to the VIIRS scale
  (trained 2012–2017, tested on unseen 2018–2021: bias −3.7 %, Spearman 0.96).
- S-NPP outage days are filled with NOAA-20; the record continues on NOAA-20 after S-NPP ends.

## Data
- NASA FIRMS — MODIS Aqua C6.1 and VIIRS S-NPP / NOAA-20 375 m active fire: https://firms.modaps.eosdis.nasa.gov/
- NASA MODIS Land Cover MCD12Q1 v6.1: https://www.earthdata.nasa.gov/data/catalog/lpcloud-mcd12q1-061
- NASADEM v001 (slope): https://www.earthdata.nasa.gov/data/catalog/lpcloud-nasadem-hgt-001
- ESA WorldCover v200 (2021): https://esa-worldcover.org/en

## Updating the app
- **UI changes:** edit files in `site/` → commit → push. Vercel redeploys automatically (~1 min).
- **Data update** (needs the raw FIRMS data locally; it is not stored in this repo):
  ```bash
  pip install -r pipeline/requirements.txt
  cd pipeline
  python harmonize.py    --data <FIRMS_folder> --out ../output
  python export_web.py   --out ../output --boundaries vn_34_provinces.geojson
  python build_vercel.py --out ../output --deploy ../site
  python kiem_tra_deploy.py ../output ../site
  ```
  then commit the `site/` folder and push.
